# 使用次数与近30天频次

在适配分之后显示“已记录使用”和“近30天”。这是当前本机台账中的实际执行记录，不是技能安装以来、全账号或所有 Harness 的完整历史。没有台账时显示“未记录”，不填0或猜“经常使用”；台账存在但没有该实例事件时写“记录期内0次”。同时注明“自开始记录起”，并可展示最近使用日期。

## 什么算一次

只有技能实际用于当前任务、已经开始按其工作流执行实质步骤后，才记录一次。同一任务同一技能，无论阶段、重试或恢复多少次都只记一次。仅发现、读取、评分、推荐、等待选择、查看帮助和对技能进行评测不记入用户使用历史。失败后仍算实际使用，不把次数当成功次数。

每项按规范化的真实 SKILL.md 路径识别；符号链接映射同一实例，同名不同路径分别计数。同一路径更新沿用次数；移到新路径视为新实例，不自动合并。跨主机、未经过技能乐团记录的使用不自动统计。

## 查询

评分 CLI 会只读查询 `~/.skill-orchestra/usage.sqlite3`，将结果附到各候选 `usage` 与结果 `usage_scope` 中。`--usage-db <路径>` 可指定另一台账。查询不创建数据库；台账损坏/不可读时评分仍可继续，次数显示“暂不可读”，不重置历史。

也可以直接查询：

```text
python3 <skill-piano>/scripts/usage.py stats <真实技能绝对路径>/SKILL.md
```

## 实际执行后的记录

总入口或独立执行者在执行了所选技能的首个实质步骤后调用：

```text
python3 <skill-piano>/scripts/usage.py record --skill <真实技能绝对路径>/SKILL.md --task-id <不含任务内容的稳定ID>
```

`--db <路径>` 如需指定，应置于 `record` 或 `stats` 之前。任务ID由当前任务确定并在任务进度记录里复用，可使用一次生成的随机UUID；不要每次重试生成新ID，也不要把任务正文、账号或私密URL当ID。工具利用唯一约束去重；程序不能证明 Agent 确实执行过，记录者必须遵守执行后才记录的要求。

首次 record 创建本地台账，记录起始时间、真实技能路径、任务ID和UTC时间，不保存任务正文，也不读取旧会话或上传资料。写入失败不阻断用户任务，应说明本次未记入，不填造次数。未装钢琴师或没有 Python 时不自动安装依赖，说明次数未记录。

## 如何解释

优先用“已记录12次，近30天4次”，不用“常用”替代数据。用户希望文字标签时，先说明标签标准；当前版本不设任意阈值。频次不加到适配分、不改变排序，也不打破最高分平局。真实用户可以在看过分数与次数后自行选择。
