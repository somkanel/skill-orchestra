# 🎼 Skill Orchestra · 技能乐团

**让合适的技能，各司其职。**

中文 · [English](README.en.md)

面向 Codex 等 Agent Harness 的技能组：**理解任务 → 比较适配 → 解释选择 → 继续完成。**

安装许多相近的技能后，不必靠记住名称来选择。技能乐团说明任务需要哪类能力，找出当前会话可见的相关技能，用同一套标准比较，并把理由讲清楚。最高分相同，先说明取舍，再由你决定。

当前为 **0.2.0 本地开发版**，尚未发布到 GitHub 或在真实 Harness 新会话中完成行为验收。程序和包装验证范围见 [验证记录](docs/validation.md)。

## 为什么叫 Orchestra

一首作品不需要所有乐器同时登场。🎼 **指挥**串联全程；🎹 **钢琴师**试奏比较，为任务择技；🎻 **首席琴师**梳理分工，让不同技能配合得当。三个角色可独立使用，也可以交给总入口协调。

命令只需记住三个词：`orchestra`、`piano`、`violin`，统一以 `skill-` 开头。音乐意象只标识角色，解释仍然具体、平实，不让修辞增加理解负担。

## 安装与更新

从本项目目录或解压后的草案包中，将 `skills/` 下三个完整目录复制到 Codex 技能目录：

| 范围 | 位置 |
| --- | --- |
| 用户级 | `~/.agents/skills/` |
| 项目级 | `<项目>/.agents/skills/` |

必须保留各目录内的引用、脚本、元信息和 LICENSE；不要复制 `docs/` 或旧草案归档作为技能。安装后新建会话，检查三个技能是否可见，再显式调用验证。宿主版本可能采用其他发现路径，应以其实际列表为准。

更新前备份同名目录，比较并保留自定义的表达和偏好。只向一个发现位置安装同一实例，避免双重安装导致同名歧义。项目当前没有在线安装命令或公开下载地址，不要使用猜测的仓库链接。

三个技能不自动修改宿主配置。独立使用钢琴师或首席琴师时，核心指令仍可运行；完整安装三者可共享表达约定与编排。

## 使用

```text
$skill-orchestra 请为这个任务选择合适的技能，解释依据后继续完成：<任务>

$skill-piano 比较当前会话中适合这次任务的技能，说明评分和取舍：<任务>

$skill-violin 只读检查我的技能库，说明哪些可以互补、哪些容易重叠。
```

单独调用钢琴师进行比较时，交付比较结果；通过总入口给出实际任务时，选择后继续执行。最高分同分时会停在选择处，等待你的回答，不以界面预选或沉默代替决定。

示意文案：

> 🎹 A 和 B 的适配分相同，差别主要在制作方式：A 沿用模板，版式更统一；B 支持定制布局，自由度更高。两者都能完成这次交付，你更看重哪一点？

## 分数如何产生

先检查必须满足的格式和环境条件，再比较交付吻合 30、任务覆盖 24、环境适配 20、约束符合 16、流程合宜 10。每项有证据和三个明确档位。未知保留区间，不适用不参与排名；分数是当前任务适配度，不是成功概率或通用质量榜。

Agent 负责读取技能、判断档位并解释理由；Python 工具负责校验输入、算分和识别决策状态。工具不会调用技能、验证证据真实性或改变宿主权限。协议与限制见 [评分协议](skills/skill-piano/references/protocol.md)。

## 运行与开发

评分工具需要 Python 3.10+，仅标准库，无 API 密钥或新增付费服务。总入口和整理流程由宿主 Agent 执行，没有一键接管所有技能的进程。没有 Python 时可以手算，但需说明未经过程序校验，不自动安装依赖。

```bash
python3 skills/skill-piano/scripts/score.py examples/comparison.json
python3 tools/check.py
python3 -m unittest discover -s tests -v
python3 tools/package.py --output /tmp/skill-orchestra-draft
```

示例中的 A/B 是合成候选，不是当前技能实测排名。打包工具生成草案 ZIP 和 SHA-256，拒绝覆盖已有同名产物；它不创建 GitHub Release，也不证明真实任务判断正确。

## 边界与隐私

显式调用可以引导流程；技能无法保证自己先被加载，也不能从上下文移除其他技能。清楚的普通任务无需额外评分；不同阶段分别选择，避免把互补技能当竞争对手。

评分工具本地运行，不访问网络或上传记录；宿主 Agent 是否使用云端推理由宿主决定。真实任务、技能路径和评估记录保存在任务目录，不随公共包分发。治理默认只读，安装、禁用或配置修改遵循用户授权。

## 使用频次

适配分后显示“已记录使用”和“近30天”次数，并注明本地台账的记录起点。没有台账显示“未记录”，不能推断历史为0。实际执行后才记录，同一任务同一技能只记一次；比较、推荐与评测不计数。频次不影响适配分或最高分同分的处理。

台账默认保存在 `~/.skill-orchestra/usage.sqlite3`，仅记录路径、稳定任务ID和时间；读取不创建文件，不扫描旧会话。同名不同路径分别记录，符号链接映射同一实例。详见 [使用记录](skills/skill-piano/references/usage.md)。这是技能乐团主动记录的本机使用，不能保证捕获所有宿主中未经过记录的调用。
