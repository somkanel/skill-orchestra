# Skill Orchestra Implementation Plan

**Goal:** 将已认可的技能乐团设计建设为本地可安装、可计算评分、可测试和可打包的项目。

**Architecture:** 总入口、钢琴师和首席琴师采用三个独立技能目录，按需读取并衔接。Agent 负责语义判断与任务执行；标准库 Python 工具验证评分输入、计算排序和决策状态，不代替宿主调度。

**Tech Stack:** Markdown、JSON、Python 3.10+ 标准库、unittest、GitHub Actions。

用户已授权本轮在当前会话实施，无需另开会话或使用子 Agent。本计划不依赖其他 Harness 的技能或不存在的工作流。

1. 复制最终草案到独立项目，保留设计目录，不复制归档。
2. 编写评分输入、证据、未知和同分行为测试，再实现 `skills/skill-piano/scripts/score.py`。
3. 更新钢琴师提示词与协议，使实际比较通过计算工具核对。
4. 编写项目检查、可重复草案打包工具及对应测试。
5. 补齐双语首页、命名说明、安装/更新、版本、许可、贡献与发布说明。
6. 运行回归、技能结构与引用检查，解压草案包验证脚本和内容校验值。
7. 记录已执行的验证与尚未执行的真实 Harness 行为评测，交付本地项目和安装包。

范围边界：本轮构建本地项目，不自动修改全局技能目录、现有技能或宿主配置，不创建远端仓库或发布 Release。模型行为评测与宿主兼容性需要单独证据。
